## About

I build software, study how systems fail, and turn those lessons into better engineering.

My interests sit at the intersection of:

`Application Security` · `Software Engineering` · `Mobile Development` · `Automation` · `Security Research`

```text
BUILD  →  TEST  →  BREAK  →  UNDERSTAND  →  HARDEN  →  SHIP
```

> I don't want to build software that only works.
> I want to build software that survives being tested.
